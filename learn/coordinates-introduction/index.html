Key points

  • Two perpendicular number lines, the x-axis and y-axis, meet at the origin O (0, 0).
  • A point is an ordered pair (x, y): x along the x-axis, then y parallel to the y-axis.
  • The axes split the plane into four quadrants: I (+, +), II (−, +), III (−, −), IV (+, −).
  • Distances follow from numbers: (1, 1) to (4, 5) has legs 3 and 4, so the distance is 5.

Plotting a point

  • Start at O (0, 0).
  • Move x units along the x-axis (right if positive, left if negative).
  • Then move y units parallel to the y-axis (up if positive, down if negative).

(3, 2): 3 right, then 2 up

Distance without a ruler

(1, 1) → (4, 5): horizontal 3, vertical 4, distance = √(3² + 4²) = 5
