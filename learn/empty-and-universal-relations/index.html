Key points

  • A relation R in a set A is a subset of A × A.
  • Empty relation: no element is related to any element, so R is the empty set.
  • Universal relation: every element is related to every element, so R = A × A.
  • Both are called trivial relations.
  • Every other relation lies between the two.
