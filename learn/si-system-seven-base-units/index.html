Key points

  • Mars Climate Orbiter (1999) was lost because one team's software gave impulse in pound-force seconds while the navigation team expected newton seconds.
  • The SI (Système International, 1960) is the one system of units used worldwide in science.
  • It has seven base units: metre (m), kilogram (kg), second (s), ampere (A), kelvin (K), mole (mol), candela (cd).
  • Every other unit is derived: newton N = kg m s⁻² (from F = ma), joule J = N m = kg m² s⁻².
