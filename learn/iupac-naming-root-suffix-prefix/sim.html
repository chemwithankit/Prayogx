How the name is put together

prefix (with its locant) + root + an / en / yn (bonds) + suffix (with its locant). Number the parent chain so the principal group gets the lowest number; if there is none, the multiple bond; then the attached group. The final "e" of -ane drops before a vowel: propane → propan-1-ol. Locants that cannot vary are left out (ethanol, propanal, propanone, propene).
