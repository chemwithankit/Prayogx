Key points

  • A relation from A to B is any set of pairs (a subset of A × B); a function gives each input exactly one output.
  • One-one: different inputs give different outputs (roll numbers). Birthdays are a function but many-one.
  • Onto: every element of B is an output. Bijective = one-one + onto; only bijective functions have an inverse.
  • A relation that is reflexive, symmetric and transitive is an equivalence relation ("is in the same class as").

Types of relations

  • Reflexive: (a, a) ∈ R for every a.
  • Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R.
  • Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R.
  • All three together: equivalence relation, e.g. "lives in the same city as".

What the chapter covers

  • Types of relations: empty, universal, reflexive, symmetric, transitive, equivalence.
  • Types of functions: one-one, onto, bijective.
  • Composition of functions g∘f and invertible functions.
