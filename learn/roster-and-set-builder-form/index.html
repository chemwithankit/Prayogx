Key points

  • Roster form: list all elements in curly brackets, separated by commas: {a, e, i, o, u}.
  • In roster form order does not matter and elements are not repeated: SCHOOL gives {S, C, H, O, L}.
  • Set-builder form: state the common property: {x : x is an even natural number, x ≤ 100}.
  • The colon means such that.
  • Use roster for small sets, set-builder for big or infinite sets.

Which form when?

FormBest forExample
RosterSmall sets{a, e, i, o, u}
Set-builderBig or infinite sets{x : x is a natural number}
