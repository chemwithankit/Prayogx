03What the experiment showed

The explanation opens once you have added the steps and found the answer yourself.

  1. States, not paths. C(graphite) + O₂, CO + ½O₂ and CO₂ are the same matter (one carbon atom, two oxygen atoms) in three states. Each state has its own enthalpy, H. We measure levels from the start, C(graphite) + O₂ = 0.
  2. The problem. We want ΔrH for C(graphite) + ½O₂ → CO but when carbon burns, some CO₂ always forms, so this change cannot be measured directly.
  3. Two reactions that can be measured (NCERT, p. 151): (i) C(graphite) + O₂ → CO₂   ΔrH = −393.5 kJ mol⁻¹ and (ii) CO + ½O₂ → CO₂   ΔrH = −283.0 kJ mol⁻¹
  4. Reverse a reaction, reverse the sign. To go from CO₂ back to CO, reaction (ii) is reversed. Its enthalpy change keeps its size and changes sign: (iii) CO₂ → CO + ½O₂   ΔrH = +283.0 kJ mol⁻¹
  5. Add the steps of the route. Start → CO₂ → CO is a route from the start to CO: ΔrH = (−393.5) + (+283.0) = −110.5 kJ mol⁻¹
  6. Two routes, one total. From the start to CO₂ directly: −393.5 kJ mol⁻¹. Through CO: (−110.5) + (−283.0) = −393.5 kJ mol⁻¹. The same start and the same end give the same ΔH, because enthalpy is a state function.
  7. An independent check. NCERT's Table 5.2 (p. 149) lists the standard enthalpy of formation of CO as −110.53 kJ mol⁻¹, which is the same change. It agrees with −110.5 kJ mol⁻¹ to the rounding of the example's data.
Hess's law. If a reaction takes place in several steps, its standard reaction enthalpy is the sum of the standard enthalpies of the steps: ΔrH = ΔrH₁ + ΔrH₂ + ΔrH₃ … (NCERT eq. 5.16).

Key takeaways

  • Enthalpy depends only on the start and the end.
  • Same start, same end → same ΔH, whatever the route.
  • Reverse a reaction → reverse the sign of ΔH.
  • So a ΔH that cannot be measured can be found by adding measured steps.

Notes. All values are per mole of the reaction as written, at standard conditions and the same temperature, from NCERT Class 11 Chemistry Part I, Unit 5: §5.4(e) (pp. 151–152) and Table 5.2 (p. 149).
