04Kohlrausch builder — assembling Λ°(AgCl)

At infinite dilution each ion migrates independently, so Λ° of a salt is just the sum of its two ionic contributions. Combine the three measured salts so that Na+ and NO3− cancel and only Ag+ + Cl− survives.

+ AgNO3 Ag⁺+ NO₃⁻ 134
+ NaCl Na⁺+ Cl⁻ 127
− NaNO3 Na⁺+ NO₃⁻ 121
= AgCl Ag⁺+ Cl⁻ 140
Λ°(AgCl) = 134 + 127 − 121 = 140 S cm² mol⁻¹

06Step-by-step solution

  1. Use the linear √c law for strong electrolytes

    NaNO3, NaCl and AgNO3 are strong electrolytes, so over this dilute range the Debye–Hückel–Onsager relation holds:

    Λm = Λ°m − A√c

    Two concentrations per salt are given, which is exactly what a straight line needs.

  2. Extrapolate each salt to infinite dilution

    With c₁ = 0.01 M (√c = 0.1) and c₂ = 0.04 M (√c = 0.2), the √c values differ by exactly 0.1, so the extrapolation collapses to a one-line formula:

    Λ° = Λ(0.01) + A(0.1),   A = [Λ(0.01) − Λ(0.04)] / 0.1  ⟹  Λ° = 2Λ(0.01) − Λ(0.04)
    NaNO3: 2(111) − 101 = 121    NaCl: 2(117) − 107 = 127    AgNO3: 2(125) − 116 = 134

  3. Build Λ°(AgCl) with Kohlrausch's law of independent migration

    Λ°(AgCl) = λ°(Ag⁺) + λ°(Cl⁻)
    = [λ°(Ag⁺)+λ°(NO₃⁻)] + [λ°(Na⁺)+λ°(Cl⁻)] − [λ°(Na⁺)+λ°(NO₃⁻)]
    = Λ°(AgNO3) + Λ°(NaCl) − Λ°(NaNO3) = 134 + 127 − 121 = 140 S cm² mol⁻¹

    Na+ and NO3− appear once with a plus sign and once with a minus sign, so they cancel identically — no individual ionic conductivity is ever needed.

  4. Convert the measured κ into a concentration

    The problem states that for the saturated solution Λm = Λ°m = 140 S cm² mol⁻¹ (legitimate: at ~10⁻⁵ M the A√c correction is only about 0.3 S cm² mol⁻¹, i.e. 0.2 %).

    Λm = 1000 κ / c  ⟹  X = c = 1000 κ / Λ°m
    X = (1000 cm³ L⁻¹)(1.40×10⁻⁶ S cm⁻¹) / (140 S cm² mol⁻¹) = 1.00×10⁻⁵ mol L⁻¹

  5. Take the logarithm

    log10(X⁻¹) = −log10(1.00×10⁻⁵) = 5

    Answer: (C) 5. As a by-product, Ksp(AgCl) = X² = 1.0×10⁻¹⁰ at 300 K, which matches the accepted value closely.

✓ Independent verification

  • Slopes recomputed from scratch: A = Δ Λ / Δ√c gives 100, 100 and 90 S cm² mol⁻¹ M−1/2; intercepts 121, 127, 134 — identical to the shortcut 2Λ(0.01) − Λ(0.04).
  • Dimensional check: (cm³ L⁻¹)(S cm⁻¹)/(S cm² mol⁻¹) = mol L⁻¹ ✓.
  • Numerical check (independent script): 1000 × 1.40×10⁻⁶ / 140 = 1.000000×10⁻⁵; −log₁₀ = 5.000000 exactly.
  • Physical sanity: Ksp = 1.0×10⁻¹⁰ against the literature value ≈1.8×10⁻¹⁰ at 298 K — right order of magnitude for a designed problem.
  • Self-consistency of the slope pattern: both sodium salts share A = 100 and only AgNO3 differs (90), consistent with the same 1:1 charge type but a different ion pair — no data point is an outlier.
  • Distractor audit: 3, 4 and 6 correspond to κ read at the wrong power of ten or to forgetting the 1000 cm³ L⁻¹ factor; none arises from a legitimate route.
