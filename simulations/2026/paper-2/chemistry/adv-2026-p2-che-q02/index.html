Electron bookkeeping

Walsh's rule for a triatomic AB₂ — count the valence electrons

Along the NO2 series the only thing that changes is the electron count on nitrogen. A 16-electron AB₂ species is linear; from 17 electrons on it bends, and it keeps bending as electrons are added — the textbook Walsh result, and exactly what the measured angles show.

06Step-by-step solution

  1. Count the electron domains on nitrogen

    Only σ-bonded atoms and non-bonding electrons on the central atom count as domains; π bonds do not.

    NO2+: 16 e⁻ → 2 σ + nothing = SN 2  ·  NO2: 17 e⁻ → 2 σ + 1 electron = SN 3  ·  NO3−: 24 e⁻ → 3 σ + nothing = SN 3  ·  NO2−: 18 e⁻ → 2 σ + 1 lone pair = SN 3

  2. NO2+ is the odd one out — it is linear

    With only two domains and no non-bonding electrons on N (isoelectronic with CO2, 16 valence electrons), the nitronium ion is sp hybridised and strictly linear.

    O=N+=O  ⟹  ∠ONO = 180° — the largest, so it must sit last.

    That alone kills (A) and (D).

  3. The remaining three all have three domains — rank them by repulsion

    Three domains give an ideal 120°. What moves a species off 120° is the character of the third domain:

    repulsion:  lone pair  >  bonding pair  >  single (odd) electron
    • NO3− — three identical N–O bonding domains, nothing else on N. Perfect D3h symmetry ⟹ exactly 120°.
    • NO2− — the third domain is a full lone pair, which repels harder than a bonding pair and squeezes the two N–O bonds together ⟹ 115.4°, below 120°.
    • NO2 — the third domain holds only one electron, which repels less than a bonding pair, so the bonds spread apart ⟹ 134.1°, above 120°.

  4. Assemble the order

    NO2− (115.4°) < NO3− (120°) < NO2 (134.1°) < NO2+ (180°)

    Read the options against this list rather than against a half-remembered rule: (C) is the tempting near-miss because it has NO2 and NO2+ in the right places but swaps the first two. The list matches (B) exactly.

  5. Answer

    (B) NO2− < NO3− < NO2 < NO2+

    A useful memory hook: along NO2+ → NO2 → NO2− you are adding one electron at a time to the same skeleton, and the angle closes 180° → 134° → 115° each time. NO3− is simply pinned at 120° by symmetry, and 115.4 < 120 < 134.1 slots it into second place.

✓ Independent verification

  • Symmetry argument (no data needed): NO3− is D3h and NO2+ is D∞h, so 120° and 180° are exact by symmetry alone — two of the four values cannot be in dispute.
  • Isoelectronic cross-check: NO2+ (16 e⁻) with CO2, linear 180° ✓. NO2− (18 e⁻) with O3 (116.8°) and SO2 (119°) — all bent near 115–119° ✓. NO2 (17 e⁻) with the 17-electron bent radicals, angle above 130° ✓.
  • Walsh's rules: for AB₂, 16 valence electrons ⟹ linear; 17–20 ⟹ bent with the angle decreasing as electrons are added. The measured 180 → 134.1 → 115.4 sequence follows the rule exactly, so the three NO2 species are mutually consistent.
  • Redundant ranking route: ranking purely by "non-bonding repulsion on N" (lone pair > bonding pair > single electron > none) reproduces the same order without using any numerical angle.
  • Distractor audit: (A) is the exact reverse of the correct order; (C) swaps NO3− and NO2−, the classic slip of forgetting that a lone pair pushes below 120°; (D) puts NO2+ below NO2, which contradicts linearity. Only (B) survives.
  • Answer robustness: the ordering is unchanged for any literature value of ∠NO2 in 121–180° and any ∠NO2− below 120°, so it does not hinge on the precise experimental numbers.

07Concepts and classification

Rules used

Steric number = σ-bonded atoms + non-bonding domains on the central atom
Repulsion: lone pair > bonding pair > single electron
SN 2 → linear (180°) · SN 3 → trigonal planar (120°), bent if a domain is non-bonding
Walsh (AB₂): 16 e⁻ linear; 17–20 e⁻ bent, angle falls as e⁻ are added
Formal charge = V − Nnb − ½Nb
