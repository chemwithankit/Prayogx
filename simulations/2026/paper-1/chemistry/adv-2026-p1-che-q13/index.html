    Understand the concept

    ΔH: which way heat flows

    At constant pressure ΔH is the heat taken in. Heat out (bonds or attractions formed): ΔH < 0. Heat in (bonds broken, strain built): ΔH > 0.

    qp = ΔH

    ΔS: how many ways

    Entropy counts the arrangements and motions available. Freedom gained (gas formed, chain unfolded, rotor freed): ΔS > 0; freedom lost: ΔS < 0.

    S = kB ln W

    Signs are fixed; ΔG is not

    ΔH and ΔS hardly change with temperature, so their signs place a process in one List-II entry. ΔG decides spontaneity at a given T.

    ΔG = ΔH − TΔS

    Reading an option

    An option is correct only if all four of its entries match. One wrong entry rejects it.

    P → 2, Q → 5, R → 1, S → 4

    1. (P) Physisorption — ΔH < 0, ΔS < 0 → (2)

      Gas molecules are held on the surface by van der Waals forces: an attraction forms, so heat is released (typical enthalpy of physisorption −20 to −40 kJ/mol or less; ≈ −15 kJ/mol for N₂ on charcoal). A molecule that flew freely in three dimensions is now confined to the surface.

      Strans(3-D gas, N₂, 77 K, 1 bar) = R[ln((2πmkT/h²)3/2 kT/p) + 5/2] = 122.3 J/K·mol
      Strans(2-D film, 0.162 nm² per molecule) = R[ln((2πmkT/h²)·a) + 2] = 56.1 J/K·mol
      ΔS ≈ 56.1 − 122.3 = −66.2 J/K·mol  ⇒  ΔH < 0 and ΔS < 0  ⇒  (2)

      Consistent with ΔG = ΔH − TΔS: physisorption is favourable at low temperature and falls off as T rises — exactly what is observed.

    2. (Q) Diamond ⟶ Graphite — ΔH < 0, ΔS > 0 → (5)

      Hess's law: ΔH = ΔcH°(diamond) − ΔcH°(graphite) = (−395.4) − (−393.5) = −1.9 kJ/mol
      ΔS = S°(graphite) − S°(diamond) = 5.74 − 2.38 = +3.36 J/K·mol
      ΔG°(298 K) = −1.9 − 298 × 0.00336 = −2.9 kJ/mol  ⇒  ΔH < 0 and ΔS > 0  ⇒  (5)

      Graphite is the standard state of carbon (ΔfH° = 0); diamond lies 1.9 kJ/mol above it. Graphite's weakly held layers vibrate in more low-energy ways than diamond's rigid 3-D network, so its entropy is higher. The change is spontaneous but immeasurably slow. Trap: ΔS = 0 (option A/B's "3") — the two solids have measurably different entropies.

    3. (R) Denaturation of protein — ΔH > 0, ΔS > 0 → (1)

      Unfolding breaks many hydrogen bonds and other non-covalent contacts: heat is absorbed (a DSC scan shows an endothermic peak; its area is ΔH, several hundred kJ/mol for a small protein). The unfolded chain can adopt an enormous number of conformations: ΔS > 0.

      two-state model: at Tm, ΔG = 0 ⇒ ΔS = ΔH / Tm
      e.g. ΔH ≈ +500 kJ/mol, Tm ≈ 347 K ⇒ ΔS ≈ +500 000 / 347 = +1441 J/K·mol
      ΔH > 0 and ΔS > 0  ⇒  (1) — entropy-driven: it happens above Tm, where TΔS > ΔH

    4. (S) Propene ⟶ Cyclopropane — ΔH > 0, ΔS < 0 → (4)

      Propene (one C=C, free CH₃ rotation) and cyclopropane (three C–C bonds at 60°, no free rotor).
      Hess's law: ΔH = ΔcH°(propene) − ΔcH°(cyclopropane) = (−2058.0) − (−2091.3) = +33.3 kJ/mol
      (the same from formation enthalpies: ΔfH°(cyclopropane, g) − ΔfH°(propene, g) = 53.3 − 20.0 = +33.3 kJ/mol)
      ΔS = S°(cyclopropane) − S°(propene) = 237.5 − 267.0 = −29.5 J/K·mol
      ΔG°(298 K) = 33.3 + 298 × 0.0295 = +42.1 kJ/mol  ⇒  ΔH > 0 and ΔS < 0  ⇒  (4)

      The ring is strained (60° angles instead of 109.5°), so it lies higher in energy; closing it turns a flexible chain with a freely rotating CH₃ into a rigid ring, so ΔS < 0. With ΔH > 0 and ΔS < 0, ΔG > 0 at every temperature. Trap: "(3) ΔH < 0, ΔS = 0" (option D) — wrong on both counts.

    Independent verification

    • Standard data. ΔcH° and S° values from standard tables; the propene → cyclopropane ΔH agrees from combustion and from formation enthalpies (+33.3 kJ/mol both ways).
    • Statistical mechanics. The Sackur–Tetrode 3-D and 2-D translational entropies of N₂ give ΔS < 0 for physisorption at every temperature and coverage tested.
    • DSC model. A two-state unfolding scan integrated numerically returns the input ΔH; ΔS = ΔH/Tm > 0.
    • Controls. Reversing Q, R or S flips both signs and leaves no printed option matching; chemisorption keeps (2).
    • Solution websites. MathonGo's published solution (their Q45) gives (C).
    • This page. Every ΔH and ΔS is computed at run time from the data and models; the signs, the List-II entries and the option are then read off — nothing is written in.
    • Answer key. Checked afterwards against the official final key printed with the paper: Q13 → C.
