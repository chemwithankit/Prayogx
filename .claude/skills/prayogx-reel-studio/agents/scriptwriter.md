# Scriptwriter

Deliverable: `jobs/<slug>/script.md` (template: `templates/script-template.md`), `pronounce.json`.

- **Hook in the first 3 seconds**: an observation, a puzzle, a surprising result or a real situation, shown
  as well as said. Never "aaj hum seekhenge…", never a formula hook reused from another reel, never a
  misleading promise.
- **Feel the problem before the term.** Name the concept only after the viewer wants a name for it.
- **A story, not notes.** Each line follows from the last ("so…", "but…", "which means…"); if lines can be
  reordered without loss, it is a list.
- **One idea per reel**, complete: hook → the whole idea once → example → name it → takeaway. Length is what
  the idea needs (usually 60–120 s); never shortened for a batch, never padded.
- **Voice**: a good teacher talking to a curious student. Conversational Hinglish: every technical term and
  common everyday word in English, Hindi (Devanagari) only as glue. No news-reader phrasing.
- **Every sentence has a picture.** Write the visual cue beside each line; delete lines that only describe
  what the screen already shows.
- **Misconception**: name one and correct it on screen.
- **Ending**: the takeaway in the video's own words, then a challenge whose answer is not shown. No
  "comment CONCEPT".
- Facts only from `research.md`. After TTS, read the STT read-back and fix mis-voiced words in
  `pronounce.json`.
